Glassbox · one-page manual · v0.5.0

Other tools show you what happened.
Glassbox tells you what went wrong.

Every Claude Code, Cowork and Agent SDK session writes a flight recorder nobody reads. Nine steps, fifteen minutes, and you'll never run an agent blind again. Nothing leaves your machine.

01 · TWO MINUTES, NO INSTALL

Open it and load the demo

Go to blueprintau.com/glassbox/app and press Load demo. That trace is the real session that built Glassbox, sanitised.

the agent's first "hello" cost 33¢, because 90,000 tokens of context loaded before it spoke.

02 · YOUR OWN SESSION

Drop a transcript on it

Drag any .jsonl from ~/.claude/projects/ (Windows: %USERPROFILE%\.claude\projects\) onto the page — or click Open folder… in Chrome/Edge and pick from a list.

wall time vs active time, tool calls, tokens served, and what it cost.

03 · THE MOMENT IT CLICKS

Click a finding

The findings panel is a fixed set of rules, no AI: retry loops, failing tools, oversized results, context over 120k, stalls. Click one.

the exact tool calls it is about, lit up on the timeline. Every selection is a permalink.

04 · FROM THE TERMINAL

Let it find your sessions

$ npx glassbox-trace # opens your newest session $ npx glassbox-trace list --last 10

id, time, size, project and the first prompt of each session. Node 18+ is the only requirement.

05 · FEED IT BACK

Hand the findings to Claude

$ npx glassbox-trace check --format md

Each finding comes with its evidence and one line on what to do differently. Paste it into your next session: "here's what went wrong last time".

the agent acknowledges the findings and changes its approach.

06 · BEFORE AND AFTER

Compare two sessions

$ npx glassbox-trace compare 81c4 9f0a

Same task, done twice: before and after you changed CLAUDE.md, Sonnet vs Opus, the run that worked vs the one that didn't. Or Compare… in the viewer.

every metric with the change, tool use side by side, findings only one of them has.

07 · WATCH IT LIVE

Follow a session as it runs

$ npx glassbox-trace watch

Serves the viewer on 127.0.0.1 and streams the transcript while Claude Code is still writing it.

tool calls landing on the timeline within a second; Follow keeps the right edge on now.

08 · THE HOOK

Let the agent read its own recorder

in Claude Code: /plugin marketplace add aldohushi1-stack/glassbox /plugin install glassbox@glassbox-trace

Every session ends with a one-screen summary; with feedback and context on, the findings go back to the agent and carry into the next session in that project. No plugin? npx glassbox-trace hook install --feedback --context.

Claude tells you, in a sentence, what it would do differently — and the next session starts knowing it.

09 · SHARE SAFELY

Show someone without showing them everything

Share mode blanks every prompt, input and result in the view; Export redacted downloads a structure-only transcript; check --redact does the same for reports. Tool names, counts, tokens and cost stay — the content goes. Then post the screenshot.

You're hooked when…

you open Glassbox before you open the diff. The diff shows what the agent changed; Glassbox shows what it cost to get there, where it looped, and what to tell it next time.
