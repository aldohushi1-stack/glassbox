Every Claude Code and Cowork session writes a transcript to ~/.claude/projects/<project>/<session-id>.jsonl. Agent SDK runs emit the same shapes as stream-json. Glassbox turns that file into a timeline, a token and cost breakdown, and a list of things a reviewer would flag: retry loops, failing tools, oversized results, context bloat, stalls.

Drop the .jsonl above, or drop the session folder to include subagent lanes. Nothing is sent anywhere. Or load the demo: the trace of the session that built this tool.

Finding the file: macOS/Linux ls -t ~/.claude/projects/*/*.jsonl | head · Windows %USERPROFILE%\.claude\projects\. Subagents live in <session-id>/subagents/agent-*.jsonl next to it.

How to read Glassbox

Timeline. One lane per agent; the main session first, subagents below it. Grey blocks are model time (from the moment the model had its input to its last streamed block). Coloured blocks are tool calls, by category. Hatched grey between turns is human idle time. Red edge = the tool returned an error. Scroll to zoom, drag to pan, press 0 to reset.

Context & cost. One bar per API request: the size of the prompt the model saw, split into cached reads (light), cache writes (mid) and uncached input (dark). The line is cumulative estimated cost.

Findings. Mechanical rules, no AI: identical calls repeated in a turn, tool error rates, results over 20k characters, context over 120k tokens, mid-session cache invalidation, responses that took over a minute and produced little, truncated outputs, hook and API errors, compaction events. Click one to highlight its evidence on the timeline. Thresholds live in TraceCore.DEFAULTS.

Tokens. Assistant messages are stored one record per content block with the usage repeated on each; Glassbox counts usage once per API request. Thinking tokens are part of output tokens, shown as a share, never double counted. Cost is an estimate from the rate card unless the file carries a reported total_cost_usd.

Share mode. Blanks every prompt, tool input, result and assistant text in the view and exports a structure-only .jsonl that keeps timestamps, usage and tool names — safe to post publicly.

Glassbox is a single HTML file with no network calls. Source and tests: see the README that ships with it.
